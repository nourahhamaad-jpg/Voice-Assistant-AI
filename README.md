# 🎙️ Voice-to-Voice AI Assistant Pipeline

An intelligent Voice-to-Voice AI pipeline built using Python. The application converts audio input to text, processes the text using a Large Language Model (LLM), and converts the response back into spoken audio.

---

## 🚀 Features & Pipeline Workflow

1. **Speech-to-Text (STT):** Converts spoken audio input into text.
2. **LLM Processing:** Processes the text prompt to generate an AI response.
3. **Text-to-Speech (TTS):** Converts the text response into clear spoken audio using `gTTS` and plays it automatically.
